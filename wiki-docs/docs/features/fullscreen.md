# Fullscreen Mode

Fullscreen mode provides an immersive viewing experience by expanding the CAD viewer to fill your entire screen.

## Entering Fullscreen

### Method 1: Toolbar Button

1. Open a DWG or DXF file in the CAD Viewer
2. Click the **Fullscreen** button (⛶) in the toolbar
3. The viewer will expand to fill your screen

### Method 2: Keyboard Shortcut

- Press `F` to toggle fullscreen mode
- Press `Esc` to exit fullscreen

### Method 3: Browser Menu

Most browsers also offer fullscreen options:

- **Chrome/Edge**: View → Enter Full Screen
- **Firefox**: View → Full Screen
- **Safari**: View → Enter Full Screen

## Fullscreen Features

When in fullscreen mode:

- **Maximized Viewport**: More screen real estate for your drawing
- **Hidden Distractions**: Nextcloud navigation and other UI elements are hidden
- **Persistent Controls**: Viewer toolbar remains accessible
- **Quick Exit**: Press `Esc` anytime to return to normal view

## Exiting Fullscreen

You can exit fullscreen mode by:

1. Pressing the `Esc` key
2. Clicking the **Exit Fullscreen** button (⛶) in the toolbar
3. Pressing `F` again
4. Using your browser's fullscreen exit command

## Browser Compatibility

Fullscreen mode works on all modern browsers:

| Browser | Support | Notes |
|---------|---------|-------|
| Chrome | ✅ Full | Best experience |
| Firefox | ✅ Full | - |
| Safari | ✅ Full | macOS and iOS |
| Edge | ✅ Full | Chromium-based |
| Opera | ✅ Full | - |

## Mobile Devices

On tablets and mobile devices:

- Fullscreen mode hides the browser address bar
- Tap the screen to show/hide controls
- Use pinch gestures for zooming
- Rotate device for landscape/portrait viewing

## Tips

- **Presentation Mode**: Use fullscreen when presenting drawings to clients or team members
- **Detailed Work**: Switch to fullscreen for detailed inspection of complex drawings
- **Multi-Monitor**: On multi-monitor setups, fullscreen uses only the current monitor
- **Performance**: Fullscreen mode may improve rendering performance on some systems
