# Features Overview

Nextcloud CAD Viewer provides a comprehensive set of features for viewing CAD files directly in your browser.

## Core Features

### 🎨 DWG and DXF Support

- Full support for AutoCAD DWG files (versions R14 through 2018)
- Complete DXF file compatibility (ASCII and binary formats)
- Accurate rendering of layers, blocks, and entities

### ⚡ WebGL Rendering

- Hardware-accelerated graphics using WebGL
- Smooth performance even with complex drawings
- Efficient memory management for large files

### 🔍 Navigation Controls

- **Zoom**: Mouse wheel or pinch gesture on touch devices
- **Pan**: Click and drag to move around the drawing
- **Fit to View**: Automatically scale the drawing to fit the viewport

### 🖥️ Display Options

- Fullscreen mode for immersive viewing
- Layer visibility toggles
- Dark/light theme support (inherits from Nextcloud)

### 📱 Responsive Design

- Works on desktop browsers (Chrome, Firefox, Safari, Edge)
- Touch-friendly interface for tablets and mobile devices
- Adaptive layout for different screen sizes

## Supported Entities

The viewer supports a wide range of CAD entities including:

- Lines, polylines, arcs, circles
- Text and MText
- Blocks and inserts
- Hatches and gradients
- Dimensions and leaders
- Splines and ellipses

## Performance Considerations

For optimal performance:

- Files under 50MB load quickly on most devices
- Complex drawings with many entities may take longer to render
- Modern browsers with WebGL 2.0 support provide the best experience
