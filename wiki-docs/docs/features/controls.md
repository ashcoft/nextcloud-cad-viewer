# Viewer Controls

Learn how to navigate and interact with CAD files using the viewer controls.

## Mouse Controls

| Action | Desktop | Laptop (Trackpad) |
|--------|---------|-------------------|
| Zoom In/Out | Scroll wheel | Pinch gesture or Ctrl+Scroll |
| Pan | Left-click + drag | Two-finger drag |
| Fit to View | Double-click | Double-tap |

## Touch Controls

| Action | Gesture |
|--------|---------|
| Zoom In/Out | Pinch open/close |
| Pan | One-finger drag |
| Fit to View | Double-tap |

## Toolbar Buttons

The viewer toolbar provides quick access to common actions:

### Zoom Controls

- **Zoom In** (+): Increase magnification by 25%
- **Zoom Out** (-): Decrease magnification by 25%
- **Fit to View** (⊡): Automatically scale to show entire drawing

### View Options

- **Fullscreen** (⛶): Toggle fullscreen mode
- **Reset View** (↺): Reset zoom and pan to default

### Layer Panel

Click the layers icon to:

- Toggle layer visibility
- See layer names and colors
- Isolate specific layers for focused viewing

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `+` or `=` | Zoom in |
| `-` | Zoom out |
| `0` | Fit to view |
| `F` | Toggle fullscreen |
| `Esc` | Exit fullscreen |
| `R` | Reset view |

## Status Bar

The status bar at the bottom of the viewer displays:

- Current zoom level percentage
- Cursor coordinates (when hovering over the drawing)
- File information

## Tips for Better Navigation

1. **Start with Fit to View**: Always begin by fitting the drawing to view to understand the overall layout
2. **Use Keyboard Shortcuts**: For frequent viewers, shortcuts significantly speed up navigation
3. **Layer Management**: Turn off unnecessary layers to improve performance and reduce visual clutter
4. **Fullscreen Mode**: Use fullscreen for detailed work or presentations
