# Introduction

Welcome to the **Nextcloud CAD Viewer** documentation! This app provides native DWG and DXF file viewing capabilities directly within your Nextcloud instance.

## What is Nextcloud CAD Viewer?

Nextcloud CAD Viewer is a powerful browser-based application that allows you to view CAD files (DWG and DXF formats) without leaving your Nextcloud environment. Built on top of [mlightcad/cad-viewer](https://github.com/mlightcad/cad-viewer), it leverages WebGL for fast, hardware-accelerated rendering.

## Key Features

- 🎨 **Native Integration**: View DWG and DXF files directly in Nextcloud
- ⚡ **Fast Rendering**: WebGL-based rendering for smooth performance
- 🔍 **Interactive Controls**: Zoom, pan, and fit-to-view functionality
- 🖥️ **Fullscreen Mode**: Immersive viewing experience
- 📱 **Responsive Design**: Works on desktop and mobile devices
- 🔄 **Easy Updates**: Simple update process from upstream cad-viewer

## Quick Start

1. Install the app from the Nextcloud App Store or manually
2. Upload a DWG or DXF file to your Nextcloud
3. Click on the file to view it in the CAD Viewer

## Requirements

- Nextcloud 33 or higher
- PHP 8.5 or higher
- Modern web browser with WebGL support
